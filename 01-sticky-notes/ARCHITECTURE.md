# Architecture

This is a small React and TypeScript app with a few clear pieces. `App` owns the list of notes through a reducer, `Toolbar` handles the creation controls, `Board` handles positioning and dragging, and `NoteView` handles the content and controls for one note. A note contains its ID, text, color, position, size, and stacking order. I kept the geometry calculations in `model/geometry.ts` so the same boundary rules apply whether a note is created, moved, or resized.

Pointer interactions stay in `Board`. While the mouse is moving, the board shows a temporary preview; it updates the reducer only when the gesture is completed. That keeps repeated drag events out of the saved state. The shared pointer helper deals with capture, releasing outside the note, and cancellation with Escape. Users can draw a note on empty space, drag a new one from the toolbar, enter an exact position and size, move existing notes, resize them, or drag them into the trash. Keyboard controls are provided on the move and resize handles, and the most recently deleted note can be restored with Undo.

Notes are saved as JSON in local storage after a short debounce and restored on page load. The storage helper checks the saved data before using it and doesn't let a storage failure crash the board. There is no backend or mock API because persistence to a server is optional for this task. The tests cover the geometry boundaries, basic note state changes, deletion/undo, and invalid or unavailable storage. The code is split enough to be easy to maintain without adding extra layers for a small assessment.
